# Mind Journal 🧠✍️

**Мови:** [English](README.md) · [Русский](README.ru.md) · Українська

Mind Journal — особисте видання Сергія Тарабана про політичну філософію,
альтернативні форми правління та футурологію. Проєкт досліджує **сайтризм** —
запропоновану модель, що поєднує людські інституції, штучний інтелект і пряму
демократію.

## Теми

- Політична теорія та альтернативні форми правління
- Сайтризм як модель кібер-тріархії
- Технології, штучний інтелект і мережеві спільноти
- Референдуми, пряма демократія та участь громадян
- Особисті нотатки, дослідження, експерименти й роздуми

## Сайт

Опублікований сайт доступний за адресою:
<https://mmortall.github.io/blogs-Mind-Journal/>.

Hugo налаштований для англомовних, російськомовних та україномовних
матеріалів. Якщо розмістити репозиторій на GitLab, цю саму структуру можна
публікувати через GitLab Pages. GitLab відображає `README.md` як огляд проєкту,
а наведені вище посилання відкривають переклади README.

Зберіть публічну версію та версію з чернетками, а потім перевірте багатомовну дослідницьку мапу:

```powershell
hugo --minify --destination public
node tools/validate-future-map.mjs public
hugo --buildDrafts --minify --destination public-drafts
```
